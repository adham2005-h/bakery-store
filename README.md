# مخبز الدفء - Bakery & Sweets Store

## التقنيات المستخدمة
HTML5, CSS3, JavaScript (Vanilla), PHP, MySQL (PDO)

## خطوات التشغيل

1. ضع مجلد المشروع داخل مجلد السيرفر المحلي (مثال: `htdocs` في XAMPP أو `www` في WAMP).
2. شغّل خادم Apache و MySQL من لوحة تحكم XAMPP/WAMP.
3. افتح phpMyAdmin وأنشئ قاعدة بيانات جديدة أو استورد الملف `database.sql` مباشرة (سينشئ قاعدة البيانات والجداول والبيانات تلقائياً).
4. تحقق من إعدادات الاتصال في `includes/db.php`:
   - `host`: localhost
   - `dbname`: bakery_store
   - `username`: root
   - `password`: (فارغة افتراضياً في XAMPP)
5. افتح المتصفح على: `http://localhost/bakery-site/index.php`

## ملاحظات
- سلة المشتريات تعتمد على PHP Session، لذا تبقى محفوظة أثناء تصفح الموقع حتى إغلاق المتصفح أو إفراغها يدوياً.
- الصور مأخوذة من روابط Unsplash مباشرة، لذا يجب توفر اتصال بالإنترنت لعرضها.

## حدود العرض التجريبي

المشروع يستخدم PHP وMySQL وHTML وCSS وJavaScript الموجودة أصلًا. السلة تعمل، لكن لا توجد خدمة لإرسال طلب أو دفع؛ صفحة السلة توضح ذلك بدل عرض تأكيد غير حقيقي.

## إعداد الاتصال

الكود الحالي يستخدم المضيف `127.0.0.1` والمنفذ `3307` في `includes/db.php`. راجع المنفذ حسب إعداد MySQL لديك؛ قد يكون `3306`. حساب root وكلمة المرور الفارغة مناسبان للتجربة المحلية فقط.

## حماية السلة

كل نموذج يرسل رمز CSRF المخزّن في الجلسة. ملف `cart_action.php` يتحقق من الرمز، ونوع العملية، ورقم المنتج، والكمية الصحيحة بين 1 و20. الإضافة المتكررة لا تتجاوز 20 قطعة لكل منتج، وإعادة التوجيه تسمح بصفحات محددة فقط.

## اختبار يدوي

استورد `database.sql` ثم جرّب إضافة منتج وتغيير الكمية وحذفه وإفراغ السلة. إرسال نموذج بلا رمز صالح يجب أن يُرفض. جرّب كمية أكبر من 20؛ يجب رفضها. الصور الخارجية تحتاج الإنترنت.
